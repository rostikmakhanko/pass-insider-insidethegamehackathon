## Brand & Style

This design system is engineered for elite match analysts, technical directors, and professional scouting departments. The visual language conveys rigorous tactical intelligence, high-cadence data digestion, and spatial clarity. It merges high-density telemetry displays with the commanding physical presence of a tactical whiteboard.

The aesthetic philosophy is **Technical Pitch Minimal-Brutalism**:
- Light, crisp viewports isolate focus onto high-fidelity pitch visualizations.
- Deliberate geometric discipline eliminates superfluous decorative flair.
- High-contrast tactical vectors (pass networks, voronoi territories, xG corridors) provide high-visibility telemetry across varied display environments from daylight dugouts to bright video analysis suites.

## Colors

The palette is anchored in clean stadium daylight and authentic pitch materials, accented by precision telemetry signals.

### Core Foundation
- **Canvas Base (`#0f172a`):** Deep navy slate forming the primary application viewport, sidebars, and structural chrome.
- **Surface Level 1 (`#f8fafc`):** Lifted card containers, telemetry panels, inspector frames.
- **Surface Level 2 (`#e2e8f0`):** Sub-cards, hovered rows, active inspector blocks.

### Tactical Pitch Palette
- **Pitch Core (`#2d6a4f`):** Outer non-playable zone and base turf tone.
- **Pitch Zone Alternate (`#40916c`):** Striped mowing bands and half-space channel highlights.
- **Emerald Accent (`#10b981`):** Pitch lines, penalty markers, success indicators, completed progressions.

### Matchplay & Data Overlays
- **Home Team Primary (`#2563eb`):** Royal blue team nodes, pass clusters, defensive pressure zones.
- **Away Team Primary (`#dc2626`):** Crimson red opposition vectors, pressing triggers, counter-attack lanes.
- **Tactical Gold (`#eab308`):** Key chance creation, xG high-danger zones, captain/MVP callouts.
- **Pass Line Vectors:**
  - High-Volume / Ground Pass (`#06b6d4`): Vibrant cyan with razor crisp path rendering.
  - Progressive / Penetrative Pass (`#facc15`): High-voltage laser yellow with directional vector heads.

### Contrast & State Rules
All pitch markups must guarantee a minimum 4.5:1 contrast ratio against both `#2d6a4f` and `#40916c`. Data labels use semi-opaque alpha masks (`rgba(255, 255, 255, 0.85)`) behind text nodes to maintain legibility when crossing dense vector clusters.

## Typography

The typographic engine uses a tripartite architecture designed for rapid match analysis:

1. **Space Grotesk (Display & Sectioning):** Delivers a technical, sharp geometric posture for dashboard titles, scorelines, phase indicators, and macro metric clusters.
2. **Inter (Interface & Analytical Narrative):** Governs structural UI, analyst notes, filter menus, and match logs. It maximizes legibility in high-density multi-column layouts.
3. **JetBrains Mono (Telemetry & Pitch Nodes):** Used across timestamps, positional coordinates (X/Y), player shirt numbers, passing accuracy metrics, and expected value readouts (xG, xA, PPDA). Monospaced alignment prevents layout shifts during live data streaming.

### Usage Standards
- All field-level metrics (e.g., `87.4% PASS`, `0.42 xG`) must be formatted in `JetBrains Mono` with tabular numbers enabled.
- Pitch nodes pair numeric markers inside 20px–24px badges using `tactical-node` styling for instantaneous visual recognition.

## Layout & Spacing

The layout is built on a responsive 16-column command-center grid optimized for widescreen displays (1440px to 2560px), reflowing to stacked modular cards on mobile viewports.

### Architectural Breakpoints
- **Desktop Pro (1440px+):** Fixed 280px left workbench (squad & timeline filter), flexible 10-column tactical pitch center stage (locked to 105m:68m pitch ratio or 16:9 viewport bounds), and 4-column right telemetry workbench (passing breakdown, xT heatmaps, event logs).
- **Tablet Landscape (1024px–1439px):** 12-column grid. Left workbench collapses to icon rail (56px); pitch occupies 8 columns; telemetry workbench takes 4 columns.
- **Mobile / Portrait (<1023px):** Single-column stacked mode. Tactical pitch pins to the top sticky frame (maintaining strict aspect ratio); event timeline and player matrices scroll vertically underneath.

### Layout Spacing Protocol
- Gutters inside technical inspection panels use `gutter-sm` (8px) to maximize data density.
- Tactical canvas margins utilize `space-lg` to create a distinct stadium boundary ring surrounding the grass pitch surface.

## Elevation & Depth

Visual hierarchy is maintained through **Tonal Surface Stacking** combined with **Low-Contrast Precision Outlines**. Heavy drop shadows are omitted to maintain a clean, crisp light-mode aesthetic.

### Layer Mechanics
- **Base Level (Canvas):** `#f1f5f9` (Zero elevation, flat).
- **Pitch Base:** `#2d6a4f` bordered by a 1px solid hairline of `rgba(16, 185, 129, 0.25)`.
- **Card Containers:** `#ffffff` with a 1px perimeter stroke of `rgba(148, 163, 184, 0.2)`. No shadow.
- **Hover / Active State:** `#f8fafc` with a 1px border shift to `rgba(148, 163, 184, 0.4)`.
- **Floating Overlays & Context Tooltips:** `#ffffff` with a 1px border of `rgba(6, 182, 212, 0.4)` and a soft shadow: `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.1)`.

### Tactical Layering
Vector graphics render across three distinct z-index tiers:
1. *Underlay:* Density heatmaps, territorial Voronoi partitions (opacity 0.25–0.4).
2. *Mid-tier:* Pitch lines (`#10b981`, 1.5px stroke), pass lines (`#06b6d4` / `#facc15`, 1.5px–3px dynamic stroke based on pass frequency).
3. *Overlay:* Player coordinate badges, key intercept tags, hover telemetry nodes.

## Shapes

The interface adopts a disciplined **Soft Precision (`1`)** shape logic:
- Standard container cards, telemetry widgets, data tables, and input controls use `0.25rem` (4px) corner radii, maintaining an angular, instrument-grade appearance.
- Secondary detail cards and modal windows step up to `0.5rem` (8px).
- Tactical player markers, match event nodes, and status indicators strictly employ circular geometry (`rounded-full`) to differentiate spatial field entities from dashboard UI containers.

## Components

### Buttons & Action Triggers
- **Primary Action (Tactical Filter/Export):** Pitch-emerald fill (`#10b981`), dark slate text (`#0f172a`), 32px height, `0.25rem` radius, `Space Grotesk` 13px bold. Hover: `#059669`.
- **Secondary Action (View Modes, Line Types):** Light surface (`#ffffff`), 1px outline (`#cbd5e1`), dark slate text (`#0f172a`). Hover: border shifts to cyan (`#06b6d4`).
- **Team Toggle Buttons:** Dynamic state indicators filled with either Royal Blue (`#2563eb`) or Crimson Red (`#dc2626`) with inset pill markers.

### Pitch Player Badges (Tactical Markers)
- 24px diameter circular node.
- Outer border: 2px solid matching the team color (`#2563eb` or `#dc2626`).
- Core fill: `#ffffff`.
- Center label: Player shirt number in `JetBrains Mono` 10px bold, dark slate (`#0f172a`).
- Hover state: Node scales to 28px, emitting a 4px outward ring pulse in team accent.

### Pass Vectors & Flow Lines
- High-speed SVG or WebGL path renders.
- **Directional Ground Pass:** Solid `#06b6d4`, line weight dynamically mapped from 1.5px to 4px according to connection count between nodes.
- **Key / Progressive Pass:** Solid `#facc15` with an animated directional arrowhead marker.
- **Incomplete / Intercepted Pass:** Dashed 1.5px stroke in `#dc2626` with 4px dash spacing.

### Telemetry Cards & Metric Blocks
- Background: `#ffffff` with a hairline top border accent (1px) indicating context (e.g., Blue for Home metrics, Cyan for passing analysis).
- Content layout: Micro-caps category label (`label-caps` in `#64748b`), followed by oversized metric readout (`Space Grotesk` or `JetBrains Mono`), and a micro delta comparison chip.

### Match Timeline & Phase Scrubber
- Full-width 28px height tracking bar.
- Base rail: `#e2e8f0` with vertical division ticks at 15-minute intervals.
- Ball possession gradient fill: Bilateral bar showing blue/red dominance percentages across match minutes.
- Scrub handle: Rectangular `#facc15` caliper marker with monospaced minute stamp (`42:18`).

### Selection Chips & Filter Pills
- Compact 22px height.
- Default: `#f8fafc` ground with `#cbd5e1` border, label in `JetBrains Mono` 11px `#64748b`.
- Active: Border color shifts to emerald (`#10b981`) or cyan (`#06b6d4`) with matching 10% alpha background fill.
